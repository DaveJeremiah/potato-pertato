# 🥔 Potato Pertato — Grade 4 Smartboard Classroom Inspirer

A retro-playful, touch-first active classroom learning platform designed for interactive smartboards and laptops.

Built for **Cambridge Stage 4 Primary English** at **Khartoum Diplomatic School (KDS) / Green Hills College (GHC)** by **Mr. Jamal Jeremiah (Dave Jeremiah)**.

---

## 🌟 Key Features

1. **🎨 6 Looping-Ribbon Learning Worlds:**
   - **Orange World:** Paper 1 Non-Fiction Exam Revision (Amazing Animals of the Earth)
   - **Purple World:** Paper 2 Fiction Exam Revision (The Secret of the Mountain Dragon)
   - **Green World:** 4-Paragraph Story & Collector's Card Block Architect
   - **Yellow World:** 10-Sentence Smartboard Punctuation Surgery
   - **Blue World:** Sentence Train Syntax Lab
   - **Pink World:** Mind Pictures & Poetry Arcade (Riddles, Kennings, Alliterations)

2. **📖 End-of-Term 1 Exam Revision Studio:**
   - **Chunked Reading Lines:** Zero page-flipping overwhelm for struggling readers.
   - **🔦 1-Tap Clue Spotlight:** Highlights evidence phrases directly in the text with scaffolding tips.
   - **🧩 P.Q.A. Stem Builder:** Students assemble complete sentences on the board to eliminate 1-word fragment answers.
   - **🔍 Vocabulary & Grammar Detective:** Interactive context clue cards for Grade 4 misconceptions (*was/were*, sentence types, connectives).

3. **🔧 Smartboard Punctuation Surgery:**
   - All 10 exact exam sentences from Paper 1 & Paper 2.
   - Touch-to-fix tiles for capital letters, direct speech punctuation, possessive/contraction apostrophes, and question tags.

4. **✍️ Story & Sentence Block Architect:**
   - Color-coded paragraph stepper (`Setting` -> `Hero` -> `Problem & Dialogue` -> `Rescue & Resolution`).
   - **🫣 Skeleton Mode:** Hides model words so students use sentence frames to write their own original stories in their notebooks.
   - **🛠️ Weak Draft Upgrader:** Step-by-step transformations from weak student drafts to Grade 4 superstar writing, plus a live classroom input tool for the teacher.

5. **✏️ Pencils Up! Notebook Bridge:**
   - Built-in classroom countdown timers (1m, 2m, 3m) to bridge digital smartboard inspiration into pen-and-paper student practice.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production (Netlify / Vercel)
npm run build
```

## 🌐 Deployment
Configured for instant 1-click deployment on **Vercel** (`vercel.json` SPA rewrite included) and **Netlify** (`dist/_redirects`).
